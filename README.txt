# NOZEMOTORSPORTS — site vitrine / boutique

Version de départ validée sur la base de la maquette.

À personnaliser avant mise en ligne :
- coordonnées, adresse, horaires
- tarifs définitifs
- photos des réalisations
- liens/boutons PayPal réels
- mentions légales et CGV
- nom de domaine

Le site est statique et peut être hébergé sur un hébergement web classique.
